# Torsion.Apps.IconConverter
A simple and lightweight utility app for converting PNG and JPG images into ICO files for use as application icons, favicons, or desktop shortcuts. The tool provides a fast, user-friendly interface where you can upload an image, automatically resize it to standard icon dimensions, and export it as a high-quality .ico file.

Perfect for developers and designers who need a quick way to generate icons without relying on complex image editing software. Supports multiple resolutions to ensure compatibility across platforms.
